# Nova PC Suite 0.2.13 preview

Installeur : `Nova-PC-Suite-0.2.13-setup.exe`. Exécutable autonome : `Nova-PC-Suite-0.2.13.exe` (WebView2 requis).

## Audit Pilotes approfondi

- Les appareils sont regroupés par famille : graphique, réseau, audio, stockage, chipset et périphériques.
- Les appareils sans pilote indiqués par Windows (code 28) et les anomalies sur les familles critiques sont séparés du reste de l’inventaire.
- L’audit reste entièrement local et en lecture seule ; il n’expose pas les identifiants matériels.
