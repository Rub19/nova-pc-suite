Nova PC Suite 0.2.0 preview — maintenance, réseau et mémoire

Téléchargez `Nova-PC-Suite-0.2.0-setup.exe` pour installer Nova, ou l’exécutable autonome si WebView2 est déjà disponible.

Nouveautés : outils de maintenance supplémentaires, mesures avant/après, nettoyage de temporaires avec mise à l’écart et récupération, démarrage utilisateur réversible, inventaire/mises à jour WinGet, diagnostic réseau et mode mémoire opt-in, audits planifiés, notifications optionnelles, vérification des versions Nova et supports constructeurs officiels. Sélection individuelle des pilotes WUA et historique avec résultats persistants bornés.

Le diagnostic réseau ne prouve pas une fuite de données. Le mode mémoire entretient le working set des seuls processus choisis sous conditions ; il peut occasionner des défauts de page et ne corrige pas une fuite mémoire. Déplacer les temporaires ne libère pas de place ; la purge irréversible est une action distincte.

Preview non signée. La validation sur Windows 10/11 et matériels dédiés, la signature Authenticode et les mises à jour automatiques signées restent à compléter. Les constructeurs sont accessibles par leurs supports officiels, sans agrégation automatique de leurs catalogues.

Tests de code et fixtures réalisés sans pilotage du bureau et sans appliquer de maintenance au PC utilisateur. Voir `docs/VALIDATION-0.2.md`. Vérifiez les téléchargements avec `SHA256SUMS.txt`.
