# Nova PC Suite 0.2.9 preview

Installeur : `Nova-PC-Suite-0.2.9-setup.exe`. Exécutable autonome : `Nova-PC-Suite-0.2.9.exe` (WebView2 requis).

## Fiche matériel plus compacte

- Les cartes de la page « À propos de ce PC » sont distribuées entre deux colonnes indépendantes : une carte détaillée ne crée plus de vide sous les cartes plus courtes.
- Les composants répétés gardent le premier élément visible et placent les suivants dans un panneau repliable accessible au clavier.
- Les mesures non retournées par Windows sont masquées de la fiche, tout en restant distinguées dans le rapport exporté.

## Limites de la preview

- Les binaires ne sont pas encore signés Authenticode. Windows peut donc afficher un avertissement d’éditeur inconnu.
- La validation manuelle complète de l’interface de l’installateur sur plusieurs versions de Windows 10/11 reste nécessaire avant une version stable.
