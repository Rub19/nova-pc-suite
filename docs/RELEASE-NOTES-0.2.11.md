# Nova PC Suite 0.2.11 preview

Installeur : `Nova-PC-Suite-0.2.11-setup.exe`. Exécutable autonome : `Nova-PC-Suite-0.2.11.exe` (WebView2 requis).

## Correctif interface

- La case du nettoyage automatique est maintenant alignée avec son titre et son explication, dans une zone cliquable complète.
- Le contrôle a un retour visuel au survol et au clavier, cohérent avec le thème Nova.

## Limites de la preview

- Les binaires ne sont pas encore signés Authenticode. Windows peut donc afficher un avertissement d’éditeur inconnu.
