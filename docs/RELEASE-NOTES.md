Nova PC Suite 0.1.0 preview — Windows 10/11 x64

Télécharger `Nova-PC-Suite-0.1.0-setup.exe` pour installer l’application, ou `Nova-PC-Suite-0.1.0.exe` pour un lancement autonome avec WebView2 déjà présent.

Fonctions : diagnostic réel, pilotes Windows Update et installation groupée confirmée avec licences, point de restauration, réparation DISM/SFC, TRIM, alimentation, stockage, démarrage, processus, sécurité, historique et assistant Ollama local optionnel.

Preview non signée Authenticode. Diagnostic réel et recherche Windows Update vérifiés dans l’exécutable (deux mises à jour proposées sur le PC de développement). Tests de garde-fous réussis ; aucune installation de pilote ni réparation appliquée. Validation complémentaire Windows 10 et opérations privilégiées sur machines dédiées requise avant une version stable.

Les pilotes sont ceux proposés par Windows Update, pas tous les catalogues constructeurs. Le nettoyage et les modifications de démarrage s’ouvrent dans les paramètres Windows. Aucune promesse de gain universel. Aucun compte ni télémétrie.

Consulter `SHA256SUMS.txt` pour vérifier les fichiers téléchargés.

Installateur et désinstallateur vérifiés localement dans un dossier de test dédié. Le paquet installe l’application, sans appliquer de maintenance au PC.
