# Nova PC Suite

Suite Windows de diagnostic, maintenance et optimisation prudente, conçue pour expliquer chaque recommandation et laisser l’utilisateur garder le contrôle.

> Projet en cadrage — voir [SPEC.md](SPEC.md), [CAPABILITIES.md](CAPABILITIES.md) et [tasks/plan.md](tasks/plan.md).

## Principes

- Local par défaut.
- Actions explicables et confirmées.
- Pas de nettoyage agressif du registre.
- Pas de commandes shell arbitraires.
- Priorité aux mécanismes Windows et constructeurs officiels.
